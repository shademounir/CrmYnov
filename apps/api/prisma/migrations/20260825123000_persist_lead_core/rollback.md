# Rollback applicatif CRMY-152

Cette migration est additive. Le rollback applicatif consiste à revenir au code précédent tout en conservant les nouvelles colonnes et tables inutilisées. Aucune suppression automatique, migration de données ou commande destructive n'est autorisée.

Avant toute suppression future, une décision Product Owner `manual-po`, un export de sauvegarde et une migration séparée seront requis.
