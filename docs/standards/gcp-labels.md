# Google Cloud labels

Required non-sensitive project labels:

| Key | Values |
|---|---|
| `application` | `crm-ynov` |
| `managed-by` | `terraform` |
| `owner` | `admissions` |
| `phase` | `foundation` |
| `environment` | `bootstrap`, `dev`, `staging`, `prod` |

Labels must never contain personal data, billing identifiers, credentials,
ticket comments, or free-form operational secrets.
