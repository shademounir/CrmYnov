# Bootstrap Phase 0

This root adopts the procedurally-created `crmynov-bst-n7x4q2` by an explicitly
authorized import. After import it exclusively owns the project, its billing
link, and the three minimal Phase 0 APIs. The three APIs are initially enabled
by a controlled procedure and imported before the first plan. The root must use
a backend prefix distinct from Foundation.

This repository revision is code-only. A plan before project and service
imports is forbidden. Do not run `plan`, `apply`, `destroy`, or `import` without
a separate Product Owner authorization. The billing account is injected
outside Git. See ADR-0006 and the Phase 0 execution runbook.
